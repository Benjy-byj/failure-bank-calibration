# Cross-system schema survey (code-level; repository heads as of 2026-09-11; single reader, evidence pointers below)
Criteria (each coded from code/prompts, not papers): (a) how a failed attempt is recorded; (b) numeric evidence attached (replicates n, noise σ, seeds); (c) any path by which a recorded failure is re-exercised; (d) the instruction the consumer receives about failures; (e) whether new proposals derive from successful nodes (success-gated supply).

Cross-system reading: 0/8 attach replicate evidence (n, σ) to a negative outcome; 5/8 re-exercise only EXECUTION failures (bugs) — a valid run that scored worse is never retried anywhere; FunSearch discards failures entirely; only [1] maintains an explicit shared negative bank, and it has no reopen path. The class where wrongful convictions live (ran fine, scored marginally worse, single seed) is unretried in every system surveyed.
